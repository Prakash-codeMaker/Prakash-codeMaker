LOCAL-FIRST BY DESIGN

Your records are stored in this browser using local storage. There is no account, server sync, analytics or employer access in this pilot. Clear browser data and the records may be lost, so export a backup.

What this pilot does not claim

Device timestamps are not independent proof. Candidate-entered details are not employer verification. An empty field means “not disclosed in this record,” not proof that an employer withheld it. OpenBrief is a community draft, not an adopted industry standard.

Import an assessment brief

Paste the text of an assessment brief or choose a .txt, .md or .html file. OpenBrief looks for exact source passages using local keyword rules. It does not send the text to a server or use an AI model.

Up to 250,000 characters. Avoid confidential instructions, personal data or material you are not permitted to copy.
