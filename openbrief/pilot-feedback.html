OpenBrief · Candidate pilot 0.4

Did the passport actually save you time?

This short feedback sheet helps evaluate whether OpenBrief makes real internship assessments easier to understand and record. Please report what happened—not what you think the product ought to do.

Privacy: This page does not send or save your answers to a server. It creates a JSON file only when you press Export. Do not include assessment text, company names, personal details, confidential work or screenshots in this feedback.

1. About the assessment

Use an assessment you are allowed to discuss, or a public/sanitised example. Do not paste the brief here.

2. Compare the two ways of creating a passport

Use the same brief for both runs. Clear the first test record before starting the second. Flip a coin to decide which method to try first; this helps reduce order bias.

Count only disclosure/timing suggestions. A blank field is not a false positive. A term that was clearly stated but not found is a miss. Accuracy here is a human judgement, not a claim that the employer verified the passport.

3. Your experience

1 = very poor / not at all; 5 = excellent / definitely.

4. Permission to share this feedback

Participation is voluntary. Only export and share the file if you agree. The organiser should use it to improve the pilot, not to evaluate your job application.
